# Making a new site from this template

Everything below is a **value to change**. No code needs to be written.

## 1. `src/nexus/config.ts` (the top block)

| Setting | What it changes |
|---|---|
| `APP_NAME` | Name on the opening screen, in the browser tab, and the letter badge if there is no logo. Overrides `platform.name` in `brand.config.json`. |
| `LOGO_URL` | Header logo (a file in `public/`, default `/logo.svg`). Replace `public/logo.svg` with the client's logo, or point this at another file. `''` shows a letter badge. |
| `SHOW_NAME_IN_HEADER` | `false` = header shows only the logo (default). `true` adds the name next to it. |
| `TAGLINE` | Line under the name on the opening screen. |
| `THEME.primary` | Main colour (buttons, active tab, NEW badge, favicon). Leave `''` to use `colors.primary` from `brand.config.json`. |
| `THEME.up` / `THEME.down` | Buy / rise / even and sell / fall / odd colours. |
| `THEME.tab` / `THEME.tabText` | Colour of the oval page tabs (Free Bots, Manual Trader...). Active tab is solid with `tabText` on it; the others are a soft tint of the same colour. |
| `THEME.glowA`, `glowB`, `lightning`, `splashFrom`, `splashTo` | Colours of the opening screen (glow, lightning, background). |
| `SOCIAL_LINKS` | Telegram / WhatsApp / TikTok icons in the header. An empty link hides that icon. |

## 2. `brand.config.json`

* `platform.name`, `brand_name`, `brand_domain`, `domain_name`: the name shown by the app's own header / footer. Keep the name the same as `APP_NAME`.
* `colors.primary`: used when `THEME.primary` is empty.
* Logo and name now come from `config.ts` (`LOGO_URL`, `APP_NAME`); you normally don't touch this file except `colors.primary` if you leave `THEME.primary` empty.

## 3. `.env.production`

* `NEXT_PUBLIC_DERIV_APP_ID`: the client's Deriv app id (the market feed uses it for its fallback connection).
* `NEXT_PUBLIC_DERIV_APP_NAME`, `NEXT_PUBLIC_DERIV_REFERRAL_LINK`, `NEXT_PUBLIC_DERIV_ENV`, `NEXT_PUBLIC_DERIV_OAUTH_SCOPES`: as for any Deriv app.

## 4. Free Bots

Drop the client's bot files in `src/pages/free-bots/bots/` and list them in `src/pages/free-bots/bots.ts`
(title, type, power index). Files load only when a bot is opened.

## Behaviour notes

* Every trade (Bot Builder, Free Bots, Hedge, Bulk, Manual, Auto Trader) goes to the real account through the Deriv API.
* Summary / Transactions / Journal are open on the right of every page on desktop. To start them closed, remove the
  `toggleDrawer(true)` effect in `src/nexus/mount.tsx`.
* Pages and bot files download only when opened. Market data for the digit circles is requested for the market on screen.
* My Bots are stored in the visitor's own browser (localStorage key `nexus_my_bots`).
* Bot Studio understands text and speech with plain rules (no outside AI service, no API key); voice needs Chrome, Edge or Safari over https.
* The Manual Trader shows no payout or return figures (they depend on the commission set on the client's Deriv app ID). The price paid appears in Transactions and Journal after the trade. Ticks default to 1 and can be changed.
* The Run panel opens on the Transactions tab.
* The Manual Trader lists the trade types the chosen market offers; the broker's own message appears if a setting isn't valid.

## Smart (advanced) bots

Bot Builder has three extra blocks (category "Smart trading"): **Switch trade** (change market / digit / ticks between trades),
**Purchase any** (buy any of 8 contract types, even if it differs from the trade type) and **Digit chance** (% of the last N ticks that were
Even/Odd/Over/Under/Matches). Bot Studio builds on them (`src/nexus/studio/advanced.ts`):
- recover a loss with another trade (opposite, a fixed trade, or the likelier of Even/Odd or Over/Under),
- pick the likelier of two sides on every trade,
- move to the next volatility after N losses in a row.
Say it in plain words, e.g. "Start with Over 3 and recover with Even or Odd depending on the probability, change volatility after 2 losses".
Six ready-made smart bots are in Free Bots (`src/pages/free-bots/bots.ts`; their power values are estimates you can edit).
Limits: smart bots use a flat stake or martingale only, and must be direct-purchase (no Payout/Ask-price blocks).

## Premium Bots tab
- Bots and their descriptions: `src/pages/premium-bots/bots.ts` (add an XML file to `src/pages/premium-bots/bots/`, then one entry).
- Banner text and the "free for a few days" badge: `PREMIUM_NOTICE` / `PREMIUM_BADGE` in `src/nexus/config.ts`
  (or `NEXT_PUBLIC_PREMIUM_NOTICE` / `NEXT_PUBLIC_PREMIUM_BADGE` in Vercel). The tab's "LIMITED" tag is in `src/pages/main/main.tsx`.
  To end the offer, delete the tab block there or remove bots from `bots.ts`.
- Thumbnail artwork: `src/nexus/premium-banner.tsx`.
- The Hub Digit Switcher bots are generated by `src/nexus/studio/alpha.ts`. Their settings (Stake, Martingale, Take Profit,
  Stop Loss, Ticks, **Scan All Markets** true/false) are in the first block ("Run once at start").
- Extra blocks these bots need: Scan markets, Best market, Rotate market, and the three small settings blocks in Trade parameters
  (`src/external/bot-skeleton/scratch/blocks/Binary/Nexus/`); the engine side is `scanMarkets` / `rotateMarket` in `trade/Ticks.js`.

## Copy trading
Followers paste a Deriv API token (personal access token, **Trade** scope). The console lists each token's options accounts with live balances
(refreshed every 20 s and after every copied trade). Every trade (pages, bots, Studio, Free and Premium bots) is copied with one call to Deriv's
`bulk-purchase` endpoint to the followers' accounts of the SAME type as the logged-in account: master on demo copies to followers' demo accounts, master on real
to their real accounts. Code: `src/nexus/store.ts` (copy section), page `src/pages/copy-trading/index.tsx`, bot hook in `trade/Purchase.js`.
The link behind "Create Copytrading Token Now" is `TOKEN_URL` in `src/nexus/config.ts`.

## Log in with API token
A **Token** button sits next to Log in / Sign up in the header (`src/components/layout/header/header.tsx`; modal and logic in `src/nexus/token-login.tsx`).
The token (Deriv personal access token, Trade scope) is checked against Deriv, saved as the session (`token_type: 'pat'`) and the app reloads and
continues like a normal login. Works for demo/real and for accounts managed by someone else. Log out clears it. Sign-up always uses Deriv's page.
